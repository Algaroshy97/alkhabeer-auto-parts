# الخبير للسيارات وقطع الغيار الكورية

موقع عربي RTL مخصص مبدئياً لشركة **الخبير** لاستيراد السيارات الكورية وقطع غيارها، مبني انطلاقاً من `libyan-business-template` دون تغيير القالب الأصلي أو موقع Dibaj.

## قبل النشر

1. حدّث `assets/js/site-config.js`: رقم واتساب، الهاتف، البريد، العنوان، القطع والسيارات المتوفرة.
2. أضف صوراً حقيقية ومصرحاً باستخدامها للسيارات والقطع.
3. راجع كل الادعاءات التجارية والأسعار والتوفر مع العميل.
4. اختبر نموذج واتساب من هاتف قبل النشر.

> رقم واتساب الحالي تجريبي. النموذج يمنع الفتح حتى يوضع رقم صحيح.

## الأصول المرئية المحلية

- `assets/images/hero_car.jpg` — صورة البطل الأصلية.
- `assets/images/car_sedan.jpg` و`car_parts.jpg` — رسوم توضيحية محلية غير مرتبطة بعلامة تجارية، حتى لا تُفهم كبطاقات مخزون حقيقي.
- `generate_assets.py` — مصدر قابل لإعادة إنشاء الرسوم التوضيحية للسيارة والقطع؛ شغّله من جذر المشروع عند الحاجة (`python3 generate_assets.py`). يتطلب Pillow.

## التشغيل المحلي

```bash
python3 -m http.server 4173 --directory .
```

ثم افتح `http://127.0.0.1:4173`.
